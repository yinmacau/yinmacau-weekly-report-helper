# yinmacau-weekly-report-helper

当前内容是周报小助手单页（页面内版本标记 `2026-11-18-dual-mode`）。样式和脚本都在 `index.html` 里，下载后即可在浏览器打开，不需要安装依赖，也不需要构建。

## 本地打开

1. 下载本仓库，或只下载 `index.html`。
2. 用浏览器直接打开该文件即可。
3. 要正式调用模型时，建议在该文件所在目录启动静态服务后再打开，例如 `python3 -m http.server 8080`，然后访问 `http://127.0.0.1:8080/`。直接用 `file://` 打开可以编辑草稿和使用模拟模式；浏览器常会拦截从 `file://` 发出的跨域模型请求。

## 浏览器

使用较新的桌面浏览器：Chrome / Edge 105 及以上、Safari 15.4 及以上，或 Firefox 121 及以上。页面依赖 `localStorage`、`fetch` 流式读取和 CSS `:has()`。窄屏会把操作条放到页面底部。

## 需要自行配置的 API

本页面没有自带服务器，也不会代替你调用模型。

- 「开始润色」和按意见改写会把草稿与密钥直接发到你填写的地址。使用前请自行选择服务商，并填写 Base URL、模型 ID 和你自己的 API Key。
- 密钥只保存在当前浏览器的 localStorage。换浏览器或换设备需要重新填写。离开公用电脑前请点「清除密钥」。不要把密钥写进这个文件。
- 地址加上 `?mock` 只进入本地模拟，不发网络请求，也不需要密钥。这不是正式润色。
- 历史记录保存在本机浏览器。导入、导出的是本地 JSON，不含 API Key。
- 个别服务商不开放浏览器跨域。请求失败时看页面里的跨域说明，并改用允许浏览器直连的兼容地址。
